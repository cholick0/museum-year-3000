A make.fun bounty entry: the museum label a museum in the year 3000 puts beside an ordinary object from today — the weekly Screen Time Report.

> Screen Time Report, c. 2025. Every Sunday the glowing rectangle confessed how long its human had stared at it. The human gasped — then stared some more.

`main.ts` writes the label to `/output/entry.txt` (152 characters, one line) and validates it against the competition gate (1–200 characters, not blank, single line, verified byte-for-byte).

Built for the [Museum of the Year 3000 bounty](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) on make.fun.
